Debounced Username Validation

Demonstrates event listeners, the debounce design pattern, and dynamic inline validation feedback.

📝 Educational Context: Debouncing limits the rate at which a function gets triggered. By waiting 500ms after the user stops typing, we avoid firing dozens of API requests per second to the server. Try typing slowly vs typing fast to see the difference in the browser's network logs!
