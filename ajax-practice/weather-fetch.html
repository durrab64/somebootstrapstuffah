Weather Fetch & Error Handling

Demonstrates how to handle completely failed network states, server-side HTTP errors, and safe loading state cleanups.

📝 Educational Context: AJAX operations can fail in two major ways:
  1. HTTP Status Errors (e.g. 404/500): The server responded, but with an error status. Fetch API promises resolve on these, so we must manually check response.ok and throw an error.
  2. Network Failures: The user is offline or the server is completely unreachable. Fetch API promises reject directly (triggering the catch block).
We use finally() to ensure loading spinners disappear regardless of success or failure.
