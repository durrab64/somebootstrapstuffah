AJAX & API Exercises Suite

A practice ground for key frontend asynchronous patterns (Fetch, Headers, Debouncing, Error Handling, CSRF)

💡 Student Guide: Click any of the interactive exercise cards below to view the UI. Each exercise is built in its own file using standard fetch() requests. The requests are intercepted and simulated locally by mock-api.js so you don't need a running backend. Open the browser DevTools (Console and Network tabs) to see the AJAX requests in action!
