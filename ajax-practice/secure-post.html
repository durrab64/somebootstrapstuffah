Secure POST & CSRF Verification

Demonstrates parsing hidden meta elements from the DOM, appending request custom headers, and sending JSON bodies in AJAX POSTs.

📝 Educational Context: Cross-Site Request Forgery (CSRF) is a vulnerability where malicious sites force actions on a logged-in user. To prevent this, servers issue a unique cryptographic token. We must read this token from the HTML meta tags (e.g. <meta name="csrf-token">) and attach it to the request header as X-CSRF-Token along with our JSON body payload {"postId": 99}.
