Secure POST with CSRF Token

Read a token from a meta tag and send it in the request header

How it works:
  1. Read the CSRF token: document.querySelector('meta[name="csrf-token"]').content
  2. Send a POST to /api/like with body {"postId": 99}
  3. Include the token in headers as X-CSRF-Token
