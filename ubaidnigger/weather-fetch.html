Weather Fetch + Error Handling

Gracefully handle network failures and HTTP error codes

How it works:
  • Network failure (offline): fetch() promise rejects → caught in .catch() → show "Network disconnected."
  • HTTP errors (404/500): response.ok is false → we throw manually → show "Weather service temporarily unavailable."
  • .finally() always re-enables the button so the UI never gets stuck.
